Key Branches of AI

AI is not just one technology. It is a family of fields, each teaching computers a different human-like skill.

Machine Learning

Systems that learn patterns from data and improve their predictions without being explicitly programmed.

Foundation
Deep Learning

Uses layered neural networks, loosely inspired by the brain, to handle complex data like images and speech.

Advanced

How Does AI Learn?

Most modern AI follows the same five basic steps. Click each step to learn more.

AI needs examples to learn from, such as thousands of labeled photos, text documents, or sensor readings.

The data is cleaned, organized, and split into a training set and a testing set so results can be checked fairly.

The model makes guesses, measures how wrong it was, and adjusts its internal weights, repeating this millions of times.

The trained model is tested on data it has never seen to check its accuracy and spot bias or errors.

The model is put into a real app, monitored, and retrained with new data so it keeps getting better.
